# 결보강 시간표 도우미

학교에서 받은 결보강시간표 엑셀(.xlsx)을 올리고 이름과 학급을 고르면, 내 시간표와 학급 시간표를 보여 주고 PNG 이미지로 저장해 주는 웹페이지입니다.

## 사용법

1. 페이지를 엽니다.
2. 결보강시간표 엑셀 파일을 끌어다 놓거나 눌러서 고릅니다.
3. 선생님 이름(성과 이름)을 입력하고 학년·반을 고릅니다.
4. "내 시간표" / "우리 반 시간표" 탭에서 확인하고 "PNG로 저장"을 누릅니다.

## 개인정보

- 올린 엑셀 파일은 **브라우저 안에서만** 읽습니다. 서버나 외부로 보내지 않습니다.
- 이 페이지에는 교사 명단이 들어 있지 않습니다. 이름은 올린 파일 안의 교사시간표에서만 읽고, 목록으로 보여 주지도 않습니다.
- 페이지 하단의 연락처는 제작자 문의용입니다.
- 입력한 이름·학년·반은 다음에 편하게 쓰도록 그 기기의 브라우저에만 기억됩니다.
- 외부 글꼴·분석 도구 등 다른 사이트에 접속하지 않습니다(엑셀을 여는 라이브러리 JSZip도 파일 안에 들어 있습니다).

## 참고

- 학급 시간표에서 노란색은 결보강시간표 엑셀에 시간교체(초록)·날짜교체(노랑)·보강(주황) 색으로 칠해진, 이번 주에 바뀐 수업입니다.
- 엑셀을 여는 데 [JSZip](https://stuk.github.io/jszip/) (MIT 라이선스)을 사용합니다.
